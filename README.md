# Internet Time Capsule: A 20-Year Encyclopedic Simulation of Network Architectures, OS Internals, and Malware Resilience

## Project Summary

This project is a huge engineering and cybersecurity laboratory developed in **GNS3**. It consists on the emulation, meticulous configuration and comparative analysis of **two absolute simulations of Internet**: one stuck in the past **20 years ago (~2006)** and another one based in the **current architecture (2026+)**.

In contrast with a tradictional web laboratory, this project realises a **deep and full disection of Operative Systems** (Kernel, Memory Management, Network Stack and Native Security), analysing how their architectonic evolution affects directly malware propagation, encryption of data and methodologies of Pentesting/Auditory from a purely practical perspective.

**NOTE:** This project has been built from scratch, with no previous advanced bases, under the philosophy *"Build in Public"*. Each technical concept, routing error, memory dump and applied mitigation is strictly documented to consolidate my networks, systems and cybersecurity fundamentals.
